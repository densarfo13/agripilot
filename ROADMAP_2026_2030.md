# ROADMAP_2026_2030

Principle: correctness · resilience · explainability · farmer trust over
complexity. No speculative features.

## 2026 H2 — Earn the pilot (READY FOR 10 → 100)
- Operator: set provider keys + run the live photo acceptance + start the 10-farmer
  supervised pilot. Collect accuracy + adoption + outcome data.
- Code: surface Evidence + Trust on the farmer result/decision card (make the
  engineered trust visible); finish Universal Scanner classes (weed/disease/equipment);
  exercise crop.health/mushroom adapters end-to-end.
- Gate to advance: live accuracy targets met + 10/50-cohort acceptance healthy.

## 2027 — Scale the pilot (READY FOR 1,000)
- Outcome-driven tuning (only from validated outcomes — no fake learning).
- Dynamic-text localization for recommendations; complete Twi/Hausa/Hindi.
- Regional knowledge depth; agronomist-review throughput.

## 2028 — Business layer (only with real feeds)
- Wire a real market-price + funding/grants feed → flip Engine 9 from honest-null
  to live (revenue/buyer/funding explanations). Never before a real source exists.

## 2029–2030 — National → Global
- Multi-region provider orchestration; Sentinel/satellite if a real feed justifies it.
- Sustained metrics + audited outcomes gate each tier (national, then global).

## Standing rule
Every sprint must increase reliability, trust, recommendation quality, or
adoption. The verdict recomputes upward from real field numbers — never from a
sandbox claim.
