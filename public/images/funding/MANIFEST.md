# /public/images/funding — funding-page imagery

Reserved for the realistic farmer / climate-smart / smallholder /
irrigation / community-farm visuals the Funding page consumes.

## Pipeline rules

- Format: WebP for real photos, SVG for illustrated fallbacks.
- Size: hero ≥ 1200px wide; cards ≥ 600px wide. WebP ≤ 100 KB.
- Lighting: natural daylight, golden-hour preferred.
- People: respectful, working farmer / community context.
- No stock-photo cliches; no neon overlays.

## Active assets (Soft Ochre system, May 2026)

| Slot | File | Usage |
|---|---|---|
| Hero band | `hero.svg` | Farmer in field at golden hour — gradient overlay applied at consumer |

## Per-program slot reservations (drop curated WebPs to enable)

| File | Concept |
|---|---|
| `climate-smart.webp` | Climate-smart farming reference photo |
| `smallholder-grant.webp` | Smallholder farmer with harvest |
| `irrigation-support.webp` | Drip / micro-irrigation in action |
| `community-farm.webp` | Community / cooperative farm scene |

When a slot is empty, the consumer falls back to `hero.svg` and
the per-card category pill colour, so a missing asset never
blanks the card.
