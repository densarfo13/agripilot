# ROADMAP_2026_2031.md — gate-based roadmap (Track B branch; vision, not commitment)

**Honesty note:** dates past 2026 are indicative. Phases advance on **evidence gates**, not on the
calendar — the same evidence-gated release ladder that governs production. A phase that hasn't met
its entry gate does not start, whatever the year says.

## Phase 0 — RELEASE (now, 2026 H2) — `master`
Scope: the Track A allowed list only (see `RELEASE_PLAN.md`).
**Exit gate:** all 12 Release criteria green with production evidence + founder sign-off.

## Phase 1 — PILOT PROOF (2026 H2)
Real farmers using Scan → tasks → journal → outcomes weekly, in their language.
Scope: pilot operations, translation burn-down, recommendation-quality tuning from telemetry,
Memory Engine extensions.
**Exit gate:** pilot metrics justify expansion (retention + weekly scan usage + outcome
confirmations trending up; the 5 north-star metrics from FOS-1 answered with data, not hope).

## Phase 2 — FARMBRAIN FOUNDATION (≈2027)
Kernel extension + Knowledge Graph v1 (entity-linking the EXISTING knowledge layer) +
Mission Control (composition over existing signals) + Voice CC honest kernel (keyword router,
feature-flagged, off /scan).
**Exit gate:** graph answers real farmer questions measurably better than flat lookup; voice
routing accuracy validated with target-language field tests.

## Phase 3 — REAL FEEDS (≈2027–2028)
One at a time, each behind its own contract: satellite imagery feed (replaces the honest stub) →
market price feed → funding program APIs. Each integration ships only when the live feed is signed,
validated, and monitored; until then screens keep saying `no_live_feed`.
**Exit gate per feed:** 90 days of live data with accuracy monitoring before any farmer-facing
recommendation depends on it.

## Phase 4 — INSTITUTIONS (≈2028–2029)
Gov/NGO/Insurance portals hardened for real institutional users; enterprise layer (multi-tenant,
RBAC, SSO, audit, API keys) driven by the first paying institutional contract's actual needs.
**Exit gate:** ≥1 signed institutional deployment in production with SLAs met for two quarters.

## Phase 5 — PLATFORM (≈2029–2031)
Partner SDK, public API GA, webhooks, GraphQL read layer, developer portal; then — only on
demonstrated ecosystem demand — plugin marketplace and the agent framework. Digital Twin graduates
from foundation to product where sensor/yield ground truth exists (IoT pilots). Predictive lines
(yield forecasting, disease prediction, climate, carbon, supply chain, livestock, drone, financial
intelligence) each require a validated model or regulated partner before farmer exposure.
**Exit gate:** third-party developers shipping on the API; model validation published per
predictive feature.

## Standing rules across all phases
1. Scan reliability outranks everything, forever — it is the trust anchor.
2. No fabricated intelligence at any phase; `no_live_feed` until the feed is live.
3. Every phase runs behind the full gate chain; farmer-facing quality precedes internal completeness.
4. This roadmap is revised from evidence at each phase exit — not extended speculatively.
