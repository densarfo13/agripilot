# COMMERCIALIZATION_PLAN — Farroway

Sequenced rollout by segment, gated on real evidence. Order = where the platform is
already strongest × where a single pilot proves value fastest. No segment ships ahead
of the evidence that it works.

## Sequencing
| Phase | Segment | Why now / readiness | Gate to advance |
|---|---|---|---|
| 1 (NOW) | **Smallholder farmers** | Core product (scan → honest recommendation → task) is built + localized (en/fr/tw/sw/ha) | the pilot scorecard goes green |
| 1 (NOW) | **NGOs** | NGO surfaces, field-officer views, enrollment, impact tracking already exist | one NGO runs ≥20 farmers with the field-officer flow |
| 2 (NEXT) | **Agronomists** | The copilot + evidence tiers + review queue make them more productive; they also label data (Workstream B) | agronomists adopt the review queue in the pilot |
| 2 (NEXT) | **Produce buyers** | Buyer surfaces exist (no payments); value = verified produce + traceability | a traceability MVP (real, non-AI) ships |
| 3 (LATER) | **Commercial farms** | Need worker/machinery/inventory modules (declared `requires_*`) | those modules built + a paying design partner |
| 3 (LATER) | **Input suppliers** | Demand signal from real recommendation volume | ≥1,000 active farms generating demand data |
| 4 (LATER) | **Governments** | Regional dashboards need consented aggregation + a privacy review | the aggregation pipeline + a gov design partner |
| 4 (LATER) | **Food companies** | Need traceability + scale + certs (SOC2/ISO `requires_infra`) | enterprise security program complete |

## Honest gating principles
- **Never sell a capability that's `no_live_feed`/`requires_model`/`requires_infra`.**
  Market prices, satellite, yield prediction, carbon credits, SOC2 are declared, not
  shipped — don't put them on a sales sheet until they're real.
- **Lead with the honest superpower:** "it tells the truth — an evidence-backed
  recommendation, and it says when it doesn't know." That's the differentiator vs
  tools that fabricate confidence.
- **Land-and-expand:** smallholder + NGO first (built + localized), monetize via
  NGO/government programs + (later) input-supplier demand, NOT by charging
  subsistence farmers for unproven predictions.

## Pricing posture (directional, not committed)
- Smallholder: free / subsidized (NGO/gov-funded) during proof.
- NGO/gov: program + dashboard licensing once impact is measured.
- Commercial/enterprise: per-seat / per-hectare once the modules + certs are real.

**NOW:** prove smallholder + NGO value in the pilot. **NEXT:** agronomist adoption +
the traceability MVP for buyers. **LATER:** commercial/gov/enterprise once their
gating modules + certifications are genuinely built — never sold ahead of evidence.
