# FIELD_SUCCESS_METRICS — Phase 10

Tracked (instrumented; live values accrue during the pilot, from `/admin/pilot-analytics`):
weekly active farmers · daily recommendations delivered · recommendation
acceptance · task completion · helpful-recommendation % · scan success % ·
return rate · farmer satisfaction.

These are **collected in the field**, not fabricated here. The trust verdict
recomputes from the real numbers as cohorts (10 → 50 → 100 farmers) report.

## Final verdict: LIMITED PILOT
Trust + evidence machinery is built, tested, and gated. The ceiling is field
evidence (real farmer + accuracy data) and provider keys — not code.
READY FOR SCALE requires the live pilot data, and is not claimed from the sandbox.
