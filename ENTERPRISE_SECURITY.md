# ENTERPRISE_SECURITY — v14 (honest status)

**Real in-app today:** RBAC role guards on admin routes, authenticated APIs,
audit logging, rate-limiting middleware, secrets kept server-side (never shipped to
the browser).

**Declared `requires_infra` (an ops + certification program, not a sprint):**
Zero-Trust networking, MFA, SSO, ABAC, full encryption-at-rest/in-transit posture,
a managed Secrets Manager, immutable audit log storage, and **SOC 2 / ISO 27001
readiness**. These are achieved with infrastructure + audited process — claiming
them from a code change would be false.

The path is real and named; the certification is not asserted as done.
