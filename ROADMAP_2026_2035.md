# ROADMAP_2026_2035.md — gate-based roadmap (Track B; supersedes ROADMAP_2026_2031.md)

**Honesty note:** dates past 2026 are indicative. Phases advance on **evidence gates**, not the
calendar. A phase without its entry gate met does not start, whatever the year says. This file
supersedes `ROADMAP_2026_2031.md` and the legacy `ROADMAP_2026_2030.md` / `ROADMAP_2030.md` /
`COMMERCIAL_ROADMAP.md` (kept as history).

## Phase 0 — RELEASE (now, 2026 H2) — `master`
Track A allowed list only (`RELEASE_PLAN.md`).
**Exit:** all 12 Release criteria green with production evidence + founder sign-off.

## Phase 1 — PILOT PROOF (2026 H2)
Real farmers using Scan → tasks → journal → outcomes weekly, in their language. Translation
burn-down; recommendation tuning from telemetry; Memory (L3) consent flags.
**Exit:** FOS-1 north-star metrics answered with data (retention, weekly scans, confirmed outcomes).

## Phase 2 — FARMBRAIN FOUNDATION (≈2027)
Kernel seams named (L4 unification) · Knowledge Graph v1 read-index (L2) · Mission Control
composition (L6) · Voice honest kernel, flagged (L7) · Agent facades over live engines (L5) ·
**Farm Records** (manual expense/revenue entry — Farroway X delta; honest, farmer-valuable,
completes the Digital Twin's economic dimension; may pull forward into late Phase 1 on pilot demand).
**Exit:** graph answers beat flat lookup measurably; voice routing field-validated per locale.

## Phase 3 — REAL FEEDS (≈2027–2028)
One contract at a time: satellite imagery → market prices → funding program APIs. Screens/agents
keep declining until each feed is signed, validated, monitored.
**Exit per feed:** 90 days live with accuracy monitoring before farmer-facing reliance.

## Phase 4 — INSTITUTIONS (≈2028–2029)
Gov/NGO/Insurance portals hardened for real institutional users; enterprise layer (multi-tenant,
RBAC, SSO, audit, white-label) shaped by the first paying contract. Financial Cloud (L9) begins
ONLY as licensed-partner integrations with consent-based data sharing — never in-house lending,
savings, insurance, or credit scoring.
**Exit:** ≥1 institutional deployment meeting SLAs for two consecutive quarters.

## Phase 5 — PLATFORM (≈2029–2031)
Public platform per `PARTNER_PLATFORM.md`: API v1 hardening → keys/scopes → webhooks → GraphQL →
SDK → portals; plugin marketplace + agent framework opening LAST, on demonstrated demand. Digital
Twin graduates where sensor/yield ground truth exists (IoT pilots). Marketplace (L8) extends to
contracts/logistics only with partners and regulatory review.
**Prediction lines (Farroway X delta):** the forecast catalog is yield · disease · market timing ·
harvest · weather risk · water needs · fertilizer timing · cash flow · inventory. Each ships ONLY
with a validated model or real data basis (cash flow additionally requires accumulated Farm
Records), and every prediction carries a confidence score + provenance — an unvalidated forecast is
an honest decline, not a guess.
**Exit:** third-party developers shipping on the API; per-feature model validation published.

## Phase 6 — GLOBAL (≈2031–2035)
Multi-country expansion: regulatory corpus per country (Compliance agent gains a real source) ·
200+ crops / broader disease coverage via curated expansion + validated models · climate & carbon
programs (verified methodologies only) · supply-chain intelligence · livestock & drone lines where
partners and data exist. Each country/program is its own gated integration.
**Exit (aspiration):** Farroway operating as an agricultural OS across multiple countries with
partner ecosystems — measured by farmer outcomes, not module count.

## Standing rules (all phases)
1. Scan reliability outranks everything, forever — the trust anchor.
2. No fabricated intelligence at any phase; `no_live_feed` until the feed is live.
3. Full gate chain everywhere; farmer-facing quality precedes internal completeness.
4. This roadmap is revised from evidence at each phase exit — never extended speculatively.
