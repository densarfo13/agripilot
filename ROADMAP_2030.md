# Roadmap to 2030

Direction, not a commitment. Each horizon is earned only by passing the one before — and the
**gate to all of it is the same** today: a real pilot with real farmers.

| Year | Ambition | Entry condition (honest) |
|---|---|---|
| **2026** | Best **Daily Farming Assistant** | Pass the internal-test acceptance run → 25-user pilot → real scan-success / retention / crash-free metrics. **This is where we actually are.** |
| **2027** | Best **Agricultural Intelligence Platform** | 2026 pilot proves daily usage + recommendation acceptance; CV/ML models validated on real field photos. |
| **2028** | **Marketplace + Finance** | Real buyers + a live price feed (today: honest `no_live_feed`); a payments/finance partner; trust metrics from 2027. |
| **2029** | **Enterprise + Government** | Pen-test + external security audit passed; multi-tenant isolation proven at scale; NGO/government pilots. |
| **2030** | **Global Agricultural Operating System** | Sustained retention + outcomes across regions; localization beyond the current 6; proven unit economics. |

## The honest now
Farroway is **pre-pilot** (GO_FOR_INTERNAL_TEST). The 2026 line — "best daily farming assistant" —
is the only horizon that is actionable today, and even it is blocked on an **operational** step
(one on-device scan + GPS run with telemetry lit), not on more code or governance.

## Roadmap discipline
Each horizon is subject to the company STOP RULE: it ships only if it improves Trust, Daily Usage,
Farmer Outcomes, Reliability, or Enterprise Readiness — measured, not assumed. We do not skip a
horizon because a later one is more exciting. Earn 2026 first.
